# فيرا — تطبيق أندرويد (يشتغل كله داخل الجوال)

التطبيق يشغّل ملف GGUF مباشرة على معالج الجوال بواسطة llama.cpp. بدون إنترنت وبدون سيرفر.

## بناء الـ APK (الأسهل: GitHub Actions، مجاني)
1. سوي مستودع جديد بـ GitHub وارفع كل محتوى هذا المجلد (انتبه يرفع مجلد `.github` هم).
2. روح تبويب **Actions** > **Build Vera APK** > **Run workflow**. (ياخذ 10-15 دقيقة)
3. بعد ما يخلص، افتح التشغيل ونزّل الملف **vera-apk** من Artifacts، فك الضغط، وثبّت `app-release.apk`.

اذا ما طلع مجلد `.github` برفعك: اعمل ملف جديد من GitHub باسم `.github/workflows/build.yml` والصق فيه محتوى الملف الموجود بالمشروع.

## الاستعمال
1. دربّ فيرا بـ `vera_train.py` وطلّع ملف GGUF، وانقله لجوالك.
2. افتح التطبيق، اضغط **النموذج** واختار الملف.
3. اختار الوضع (عراقي / فصحى / ترجمة / برمجة) واكتب.

## اذا فشل البناء
- افتح `app/src/main/cpp/CMakeLists.txt` وغيّر `GIT_TAG b5400` لـ `b5300` او `b5500`، ثم ارفع التعديل.
- جوالات قديمة (قبل 2018) ممكن ما تشتغل بسبب dotprod. امسح السطر `GGML_CPU_ARM_ARCH` وأعد البناء.
- الشاشة تعرض الخطأ؛ ارسله لي واصلحه.

## ملاحظات
- المعمارية arm64 فقط (كل الجوالات الحديثة).
- السرعة تعتمد على الجوال: نموذج 1.7B يعطي عادةً عدة توكنات بالثانية، و8B أبطأ بكثير.
